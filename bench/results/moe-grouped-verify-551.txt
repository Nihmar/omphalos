## 2. Scenarios (tools/scenario_speed.py, MTP, n-gram off / on, KV Q4/Q4, greedy)

Two runs per variant, alternated (rows run 1, slots run 1, rows run 2, slots run 2). Every
cell wrote the same text in all four runs (text_sha256 equal per scenario and n-gram).

| scenario | n-gram | per slot (t/s) | grouped (t/s) |
|---|---|---|---|
| edit-cc | off | 85.0 / 82.3 | 82.9 / 84.4 |
| edit-cc | on | 98.2 / 93.5 | **117.8 / 121.0** |
| edit-py | off | 90.0 / 70.4 | 88.6 / 88.6 |
| edit-py | on | 78.8 / 70.6 | **88.5 / 87.9** |
| prose | off | 91.2 / 82.9 | 93.5 / 94.1 |
| prose | on | 89.2 / 86.7 | 91.2 / 90.4 |

The second per-slot run has three low cells (70.4, 82.9, 70.6) that the first does not: with
MTP alone (2-token blocks, -5 % per step above) the change is within the noise. With the
n-gram drafts (up to 16-token blocks): edit-cc +23-26 %, edit-py +12-25 %, prose +2-4 %, and
on edit-py the n-gram drafts no longer lose against MTP alone (88.5 vs 88.6; per slot
78.8 vs 90.0, #542).
