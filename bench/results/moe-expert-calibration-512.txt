# MoE expert cache: the calibrated fixed set (#512 step 3)

Model: Ornith-1.5-35B-A3B-Q4_K_M.omph, auto host budget (186 of 256 experts per
layer in VRAM: 154 fixed + 32 LRU slots; 7.24 GiB pinned). The fixed set is each
layer's 154 most chosen experts, from `<model>.omph.experts`, written by
`omph-run --moe-counts` over six calibration prompts that are NOT the evaluation
ones (JavaScript debounce/throttle, a bash backup script, an English adventure
story, an Italian question on the judicial systems, a train word problem with
thinking, a summary of the 2008 crisis; 400 greedy tokens each, 19.1k picks per
layer). Without the file the fixed set is experts 0..153 (by id, as in #514).

Decode: `OMPH_TIMING=1 omph-run ... --gemv --generate 400`, step gpu, median of
the 400 steps, median of 5 runs; the evaluation prompts of
moe-expert-cache-512.txt.
